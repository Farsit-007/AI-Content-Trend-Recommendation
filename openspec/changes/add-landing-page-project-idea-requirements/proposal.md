## Why

The TrendBridge hackathon project needs a public-facing landing page to communicate what the product does, why it exists, and what problems it solves — both for judges evaluating the project and for prospective users like the Programming Hero marketing team. Without a landing page, the project has no front door.

## What Changes

- Add a new React landing page at `frontend/` with a complete single-page layout
- Includes hero section, problem statement, solution overview, feature highlights, and a call-to-action
- Presents TrendBridge's value proposition in a compelling, visually polished format
